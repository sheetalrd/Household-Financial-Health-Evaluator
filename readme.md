Household Financial Health Evaluator

A beginner-friendly LangGraph learning project that evaluates a household's financial health from three perspectives:

Cash flow
Debt pressure
Savings readiness

The project demonstrates how LangGraph can coordinate multiple specialist nodes, run them in parallel, combine their results, and then route the workflow based on a classification decision.

Disclaimer: This project is for educational purposes only. It is not professional financial advice.

What does this project do?

The application asks the user for basic household financial information:

Monthly income
Essential costs
Discretionary spending
Total debts
Current savings
Savings goal

It then sends the financial information through three analysis nodes:

                    ┌──> Cash Flow Analysis ───────┐
                    │                               │
START ──────────────┼──> Debt Pressure Analysis ───┼──> Classification
                    │                               │
                    └──> Savings Readiness ────────┘
                                                        │
                                      ┌─────────────────┴─────────────────┐
                                      │                                   │
                                      ▼                                   ▼
                              Stable Budget Plan                 Recovery Plan
                                      │                                   │
                                      └─────────────────┬─────────────────┘
                                                        ▼
                                                       END

The three specialist analyses can run independently.

After all three analyses are available, the application classifies the household budget as:

STABLE
NEEDS CORRECTION

The classification determines which final plan is generated.       

LangGraph concepts demonstrated

This project is designed to demonstrate several important LangGraph concepts.

1. State management

The budgethealthState Pydantic model represents the information flowing through the graph.

It contains the household's financial data:

income
essential_costs
discretionary_spending
debts
current_savings
savings_goal

It also contains the results generated by the graph:

cash_flow_analysis
debt_pressure_analysis
savings_readiness_analysis
budget_health_classification
health_reason
final_plan
messages

The state is passed between nodes.

2. Nodes

Each function represents a node in the graph.

The project has three specialist analysis nodes:

analyze_cash_flow
analyze_debt_pressure
analyze_savings_readiness

It also has:

classify_budget_health
stable_budget_plan
budget_recovery_plan

Each node has one responsibility.

3. Parallel execution

All three specialist analyses start from START:

graph.add_edge(START, "analyze_cash_flow")
graph.add_edge(START, "analyze_debt_pressure")
graph.add_edge(START, "analyze_savings_readiness")

This creates three independent branches.

Conceptually:

             ┌── Cash Flow
             │
START ───────┼── Debt Pressure
             │
             └── Savings Readiness

These analyses do not depend on one another.

4. Fan-in

After the three specialist nodes finish, they all connect to:

classify_budget_health

This is the fan-in part of the graph.

Cash Flow ───────────────┐
                         │
Debt Pressure ──────────┼──> Classification
                         │
Savings Readiness ──────┘

The classification node uses the results from all three analyses.

5. Conditional routing

After classification, the graph chooses one of two paths:

graph.add_conditional_edges(
    "classify_budget_health",
    lambda state: "stable_budget_plan"
    if state.budget_health_classification == "STABLE"
    else "budget_recovery_plan",
)

The graph therefore behaves differently depending on the classification.

                 Classification
                       │
              ┌────────┴────────┐
              ▼                 ▼
           STABLE       NEEDS CORRECTION
              │                 │
              ▼                 ▼
        Maintenance          Recovery
           Plan                Plan
6. Graph compilation

The graph definition is converted into a runnable graph using:

compiled_graph = graph.compile()

The compiled graph can then be executed with:

compiled_graph.invoke(...)
